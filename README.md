# AI Article Generator Pro

A powerful WordPress plugin that automatically generates high-quality, SEO-optimized articles using AI. Create engaging, humanized content with just a prompt.

## Features

### 🤖 AI-Powered Article Generation
- Generate complete, ready-to-publish articles from a simple topic/prompt
- Uses Claude AI for high-quality, intelligent content creation
- Story-format articles that readers love
- Researches and references 100 top websites for credibility

### 📸 Featured Image Generation
- Automatically generates or finds perfect featured images
- Integrates with Unsplash for high-quality images
- Optional DALL-E integration for AI-generated images

### 🔍 Plagiarism Detection
- Built-in plagiarism checker to ensure 100% original content
- Optional Copyscape API integration for professional checking
- Detailed plagiarism reports and matching percentages

### ✍️ Grammar & Style Checking
- Advanced grammar and spelling checks
- Readability analysis and suggestions
- Phrase improvement recommendations
- Humanization checker to ensure natural-sounding content

### 📊 Content Quality Analysis
- Readability scores and improvements
- SEO optimization analysis
- Engagement factor evaluation
- Content structure validation
- H2/H3 heading verification
- Word count and density analysis

### 🚀 Automatic Publishing
- Optional auto-publish feature to instantly publish articles
- Manual review mode for safety
- Bulk article generation capability

### 📚 Article Library
- Manage all generated articles in one place
- Filter by status, category, and date
- Quick edit and preview options
- Track article performance

## Installation

### Requirements
- WordPress 5.0 or higher
- PHP 7.4 or higher
- Active WordPress site with admin access

### Setup Steps

1. **Upload Plugin**
   - Download the plugin files
   - Upload to `/wp-content/plugins/`
   - Activate in WordPress admin

2. **Configure API Keys**
   - Navigate to `AI Article Generator → Settings`
   - Add your Claude API key from [Anthropic Console](https://console.anthropic.com/account/keys)
   - (Optional) Add Unsplash API key for custom image search
   - (Optional) Add Copyscape key for plagiarism checking

3. **Generate Articles**
   - Go to `AI Article Generator → Generate Article`
   - Enter your topic/prompt
   - Select options (plagiarism check, grammar check, etc.)
   - Click "Generate Article"

## Configuration

### Required Settings
- **Claude API Key**: Essential for article generation
  - Get from: https://console.anthropic.com/account/keys

### Optional Settings
- **Unsplash API Key**: For improved image sourcing
  - Get from: https://unsplash.com/developers
- **Copyscape API Key**: For professional plagiarism checking
  - Get from: https://www.copyscape.com/api/
- **OpenAI API Key**: For DALL-E image generation
  - Get from: https://platform.openai.com/account/api-keys

## Usage

### Basic Article Generation
1. Go to Admin Dashboard → AI Article Generator
2. Click "Generate Article"
3. Enter your topic (e.g., "How to start a successful blog in 2024")
4. (Optional) Enter a specific title or let AI generate one
5. Choose quality checks (recommended: all enabled)
6. Click "Generate Article"
7. Review the generated content, plagiarism score, grammar analysis, and quality metrics
8. Click "Edit Post" to refine or "View Post" to see the result

### Advanced Options
- **Auto-publish**: Enable in settings to automatically publish articles
- **Grammar Checking**: Detailed suggestions for improvement
- **Plagiarism Detection**: Ensure content uniqueness
- **Featured Images**: Automatically sources or generates images

## FAQ

**Q: Do I need multiple API keys?**
A: Only Claude API key is required. Other APIs are optional for enhanced features.

**Q: How long does article generation take?**
A: Typically 30-90 seconds depending on article length and complexity.

**Q: Can I edit articles before publishing?**
A: Yes, articles are saved as drafts by default unless auto-publish is enabled.

**Q: Is the content 100% original?**
A: Yes, Claude generates original content. Use the plagiarism checker for verification.

**Q: Can I customize article tone/style?**
A: Yes, customize in the "Content Preferences" section of Settings.

**Q: How many articles can I generate?**
A: Limited only by your API usage and WordPress post limits.
